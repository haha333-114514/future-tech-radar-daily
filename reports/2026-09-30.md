## Klarity v0.7.5.1

**图像修复 · SEP 30 RELEASE**

本地离线的图像/视频修复工具，把 NAFNet 去噪与去模糊、Real-HAT/Real-ESRGAN 超分和 RIFE 插帧放进 GUI 与 CLI；今天的版本提供 Windows、Linux CPU 安装包，并补上 FFmpeg 9 兼容、双平台 CI 和安装器修复。

这是今天最容易直接试用的一项：预编译包不需要 Python 或 GPU，Lite 模型约 204 MB、最低约 4 GB 内存；Heavy 模型约 888 MB、建议 16 GB 内存。视频处理仍需 FFmpeg，CPU 输出质量不变但速度会明显慢于从源码配置 CUDA。

MIT 主程序 · Windows / Linux CPU 包 · Lite 204 MB · Heavy 888 MB

[原始来源](https://github.com/HAKORADev/Klarity/releases/tag/v0.7.5.1)

## FluxFlow

**超分辨率 · SEP 29 CODE + WEIGHTS**

面向天文图像的保守流匹配超分，公开了训练、推理、评测代码和 2×/4× 的 epoch-300 权重；推理用观测一致性修正约束生成结果，并同时评估 PSNR/SSIM、源通量误差与目标检测 F1。

它的价值在于没有只给视觉样例，而是把物理观测模型和源检测指标放进复现路径。默认环境是 Python 3.10+、PyTorch CUDA 11.8，CPU 理论可装但不适合批量；训练数据未随仓库提供，根目录也未声明许可证，因此更适合研究验证，暂不宜直接用于生产。

2× / 4× 权重开放 · Python + CUDA 11.8 · 数据与许可证需另核对

[原始来源](https://github.com/I2WM/FluxFlow)

## ChromatiX

**FPGA / VHDL · SEP 29 NEW**

把 ModRetro Chromatic 的 Gowin GW5A-25 FPGA 设计重建为 LiteX 工程：开放 PSRAM、视频、系统监控和 USB 2.0 路径，并增加 320×288 UVC 采集、虚拟卡带、USB 调试桥及 VexRiscv BIOS 模式。

它把硬件、固件、Verilator/GHDL 仿真和自动截图/按键测试连成一条可检查链路；但完整综合仍要求 Gowin EDA 1.9.12.04，README 所称预编译 bitstream 在当前 GitHub Releases 中尚未见到对应资产，刷写前应先确认文件、备份原始镜像并验证恢复流程。

GW5A-25 · LiteX · Gowin EDA + openFPGALoader · GPL-3.0 / BSD-2-Clause

[原始来源](https://github.com/enjoy-digital/chromatix)

## RTL MBIST Fault Coverage

**FPGA / VHDL · SEP 28 · 非今日发布**

一套 64×8 March C− 内存自测控制器与独立事务检查器，在 Artix-7 XC7A35T 上完成 50 MHz 实现，并用 XSim/Icarus 自动覆盖四类共 2,048 个单故障实例；还给出 Nangate45 综合与门级回归。

证据比热度更重要：无 ILA 的正常构建为 98 LUT、63 寄存器、1 个 RAMB18，WNS +14.474 ns；三次正常板测 PASS、两次受控故障 FAIL，ILA 核对全部 640 个请求。限制是故障模型仍不含耦合故障，ASIC 结果只是布局前估计，仓库尚未声明许可证。

Artix-7 · 50 MHz · 实板 ILA + 2,048 故障实例 · 许可证未声明

[原始来源](https://github.com/HugoHuang-dev/rtl-mbist-fault-coverage)

## robolings

**具身智能 · SEP 29 LEARNING KIT**

把机器人学习拆成 43 个可补全的小函数，覆盖旋转、运动学、灵巧手、控制、模仿学习、扩散策略和流匹配；只依赖 NumPy，完整测试不到一秒，并提供中文题面与参考解。

适合想真正理解 action chunking、DDIM、阻抗控制等基础组件的人，在普通电脑上即可运行；它明确没有 GPU、仿真器、感知或实体机器人闭环，因此应视为教学与单元测试材料，而不是可部署的 VLA 或实机控制栈。

MIT · Python 3.10+ · NumPy · 无 GPU / 无仿真 / 无实机

[原始来源](https://github.com/12-Twelve-12/robolings)

## Autonomous OS 关机可靠性更新

**具身智能 · SEP 30 SOURCE UPDATE**

面向 Autonomous Lamp、Reachy Mini 等实体平台的机器人软件栈，今天修复 HAL 关机完成状态与延迟 RGB 帧重新点亮 LED 的问题，并加入 HAL 退出后的 Lamp LED blackout 服务及自动测试。

这类关机边界处理不如新模型醒目，却是实体设备安全与可预期行为的一部分。项目支持 Raspberry Pi 4/5、CM4、OrangePi 4 Pro 等板卡，但模型推理可依赖远程服务；本次是主分支提交而非新标签，公开证据以代码和自动测试为主，未见针对该改动的新实机测试报告。

Lamp / Reachy Mini 等 · Pi / OrangePi · 源码更新 · 非新 Release

[原始来源](https://github.com/autonomous-ai/autonomous-os/commit/92fffbd)

## Zed v1.22.0

**AI 编程编辑器 · SEP 30 RELEASE**

Zed 的稳定版为新 subagent 增加按次选模型与自动上下文压缩，动态获取 OpenCode 模型列表，并加入命令行 diff 的 unified/split 切换；Windows 同时补上 Mica 背景和多项高 DPI、UNC 路径与任务路径修复。

## SQLite：浏览器 kvvfs 锁语义加固

**数据库内核 / WASM · SEP 30 SOURCE UPDATE**

SQLite 的 JS/WASM kvvfs 路径重做 xLock、xUnlock、xCheckReserved 与 xSleep，并补充同一存储被多个连接访问时的锁错误测试；同时新增不抛异常的 Stmt.resetNoThrow()。

这类改动展示了经典数据库如何把文件锁语义映射到浏览器存储，是源码精读的好切口；提交说明也明确早期重构本身并不能证明正确性，测试随后才补上。kvvfs 的并发边界不同于原生文件系统，应用仍要验证多标签页、崩溃恢复和持久化语义。

Public Domain · SQLite WASM / JavaScript · 源码提交 · 非 Release

## 今日深挖：今日深挖 · ChromatiX

ChromatiX 值得长期跟踪，因为它不只是移植一个 Game Boy 核，而是在消费级 FPGA 产品上把 LiteX SoC、PSRAM、USB 2.0、视频、固件和自动化测试串起来。USB CDC 调试桥可以模拟按键、读取状态和 PSRAM，UVC 能捕获画面，Verilator/GHDL 仿真还能复用 ROM、按键脚本与 PNG 帧，这让回归测试有机会从‘看屏幕’变成可自动判定。局限同样明确：目标器件是特定的 GW5A-25，完整构建仍依赖指定版本的 Gowin EDA；Game Boy 核及生成 bitstream 受 GPL 约束；当前 Releases 页面只见媒体资产，README 所述预编译 bitstream 尚需维护者补齐或用户自行构建。建议下一步先跑 Verilator 的 stripes ROM 测试并确认 CI，再核对 release 校验值；只有在备份原厂 flash、确认 JTAG 恢复和 USB 枚举后，才在实机上尝试 standard 构建。
