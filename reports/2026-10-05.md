## vLLM v0.31.0：GPU 权重常驻与请求隔离

**LLM 推理服务 · OCT 05 RELEASE**

新增 vllm preload 权重缓存守护进程，让量化后权重跨引擎重启保留在 GPU；另有实验性 CRIU 初始化快照、更多推测解码、并行调度和 KV 压力控制。

生产价值还包括默认拒绝每请求多模态处理参数、补强 prefix cache 与 LoRA 路径隔离。提供 CUDA 13/12.9、ROCm、XPU、CPU 和 macOS CPU 构建，但破坏性变更多；应先测重启时间、常驻显存、p95 延迟、并发和失败回滚。

Apache-2.0 · GPU / CPU 服务端 · preload · CRIU · 安全边界

## MuJoCo 3.15.0：执行器阻尼语义发生破坏性变化

**机器人仿真 · OCT 05 RELEASE · 仿真**

dampratio 改用运行点 qpos0 的操作空间惯量，纳入耦合、腱和 armature；同时加入实验性 Stable Neo-Hookean 3D 柔性体、胶囊 multicontact、insidesite protrusion 传感，以及超过 2 GiB 模型序列化支持。

这会改变多关节链、腱和 site actuator 的实际阻尼，旧策略即使代码能跑，动态响应也可能不同。它是仿真引擎更新，不代表真实机器人性能；迁移前应对相同初态、控制器增益、能量和接触轨迹做回归，并单独标注 sim-to-real 重新验证。

Apache-2.0 · CPU / GPU 仿真 · dampratio breaking change · 非实机

[原始来源](https://github.com/google-deepmind/mujoco/releases/tag/3.15.0)

## mise v2026.10.3：秘密不再进入会话差异与环境缓存

**开发环境 · OCT 05 RELEASE**

秘密值改为在 __MISE_DIFF / __MISE_SESSION 中保存摘要，包含秘密的环境不再写入 env cache；同时加入 Stow 风格 dotfile groups、可模板化 Compose bootstrap 和冲突检测。

## Cua SDK v0.4.1：跨进程 token refresh 改为 single-flight

**计算机使用 Agent · OCT 05 RELEASE**

补丁将认证 token 刷新合并为跨进程 single-flight，并保持已有 session 存活，降低多个 Agent/工作进程同时刷新导致的竞态和重复认证。

## 今日深挖：今日深挖：vLLM 的快速重启是一种状态管理能力

preload 的核心不是让稳态推理更快，而是把“已量化权重”从单个引擎生命周期中抽离出来，让更新与故障恢复少付一次装载成本；CRIU 快照则进一步尝试恢复已初始化引擎。局限是常驻权重会长期占用 GPU，快照仍实验性且范围有限。建议用真实模型记录冷启动、preload 重启、显存驻留、并发 p95 和回滚五组数据，再决定是否用于生产。

[查看原始项目](https://github.com/vllm-project/vllm/releases/tag/v0.31.0)

## 信号与噪音

判断：把“快速重启”当成“更低稳态显存”是误读。权重缓存恰恰依赖显存常驻，价值在恢复时间，不是空闲资源占用。
