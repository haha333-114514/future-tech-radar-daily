## ONNX Runtime 1.28.3：集中修复内存安全与图校验

**端侧模型运行时 · OCT 03 RELEASE（中国时区）**

修复 EmbedLayerNormalization shape inference 越界、sub-byte buffer 复用造成 heap overflow、Loop/Scan initializer 越界，以及 ConvTransposeWithDynamicPads 等路径；同时拒绝不合法 graph/subgraph 结构。

这类补丁对桌面、移动和边缘部署比新增算子更重要，因为模型文件可能来自外部。版本还修复 plugin EP 单 tensor 传输的 stream 保留，并补 ARM64、Android、NuGet 等打包基础设施；采用方应重新跑模型加载、恶意/损坏模型和目标 EP 回归。

MIT · CPU / GPU / NPU / Mobile · 内存安全 · 模型校验

## pnpm v12.9.0：登录凭据不再随跨域重定向转发

**Node.js 工具链 · OCT 03 RELEASE（中国时区）**

pnpm login 修复把请求体凭据转发到另一 origin 的问题；同时加入 per-registry networkConcurrency、StackBlitz WebContainer WASM 路径和更完整的 store 项目记录。

安全修复影响使用私有 registry、镜像与 SSO 重定向的开发环境。新版也修复 Android store lock、frozen lockfile、hoisted filtered install 和 optional dependency 失败处理；升级后应检查内部 registry 的重定向与 CA 配置。

MIT · Node.js · 跨平台 · credential redirect · registry 限流

[原始来源](https://github.com/pnpm/pnpm/releases/tag/v12.9.0)

## Immich v3.3.0-rc.2：ML 内存路径与移动备份继续收敛

**自托管相册 · OCT 03 RELEASE CANDIDATE**

设置 MACHINE_LEARNING_MODEL_REVISION=v2 可启用新内存/性能路径；RC2 修复 TensorRT-RTX session 串行化、half-precision 空数组、OpenVINO 2026.4.1，以及 iOS 后台批次、重复上传、缩略图和共享相册信息。

适合愿意测试的人，不适合直接覆盖家庭唯一图库。官方明确是 RC，要求先备份数据库和媒体库；服务端用 Docker Compose，移动端通过 APK/TestFlight。性能和内存收益未给统一硬件基准，应在副本库测人脸识别、视频转码和后台同步。

AGPL-3.0 · Docker · Android / iOS · RC · ML revision v2

[原始来源](https://github.com/immich-app/immich/releases/tag/v3.3.0-rc.2)

## mise v2026.10.1：超时与 Ctrl-C 真正终止任务树

**开发环境 · OCT 03 RELEASE**

mise run --timeout 现在停止实际任务，Windows 使用 taskkill /F /T；单次 Ctrl-C 允许任务清理后以 130 退出。还修复 Windows daemon、Node IPC shim、Rust lockfile 和 GitHub asset 误选 sidecar。

对把 mise 当任务编排器的项目，这是失败恢复而不是小体验改进。raw=true 任务不受整轮 timeout 终止，Windows daemon 还依赖新版 pitchfork；升级后应专测嵌套任务、Docker Compose、Ctrl-C 与超时后的孤儿进程。

MIT · Windows / Linux / macOS · timeout · Ctrl-C · daemon

[原始来源](https://github.com/jdx/mise/releases/tag/v2026.10.1)

## Ultralytics 8.4.172：OBB 裁剪、AMP 匹配与 INT8 校准修复

**视觉模型部署 · OCT 03 RELEASE**

旋转框 crop 现在按 OBB 对齐；RT-DETR Hungarian cost 改用 float32 避免 AMP 精度误配，AIFI 修非方形特征图，NaN 恢复与 resume 状态也得到修正；小数据集可完成 OpenVINO INT8 calibration。

适合检测、跟踪和边缘导出的工程用户，特别是 OBB 与小样本校准。JetPack 5 Docker 的 OpenBLAS NaN 也有修复；Ultralytics 采用 AGPL/企业双轨许可，商用集成需核对条款，且这些修复不等于所有任务精度提升。

AGPL-3.0 / 企业许可 · Python · JetPack / OpenVINO · OBB · INT8 · AMP

[原始来源](https://github.com/ultralytics/ultralytics/releases/tag/v8.4.172)
