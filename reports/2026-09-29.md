## swin2sr-rs v0.2.0

**超分辨率 · SEP 28 RELEASE**

用 Rust 和 CUDA 独立实现 Swin2SR 推理，提供单一自包含二进制、CPU 回退、自动分块和 safetensors 权重，覆盖经典、真实世界、压缩图像与轻量模型的 2×/4× 超分。

它不要求 Python、PyTorch、ONNX Runtime，甚至运行时不要求安装 CUDA Toolkit，适合离线 CLI 与批处理；但当前预编译版仅面向 Linux x86-64，GPU 至少需计算能力 6.1，项目很新且尚缺跨平台与广泛质量基准。

MIT · Linux x86-64 · CPU / CUDA · 19–82 MiB 权重

[原始来源](https://github.com/jacobsparts/swin2sr-rs/releases/tag/v0.2.0)

## VGGT-Diff

**视频 / 3D · CODE RELEASE**

把视觉几何模型与扩散视频模型结合，用稀疏多视图和相机轨迹生成新视角视频；官方示例以 6 张来源图和一条 80 帧轨迹作为输入。

几何条件有望减少纯视频扩散在视角变化时的结构漂移，但目前项目自己的半分辨率、全分辨率权重仍标为 TODO，无位姿版本也未开放；还需申请 1B 规模基础权重并配置 Python/CUDA，现阶段更适合研究复现而非即装即用。

研究用途 / 非商业 · Python + CUDA · 关键项目权重待发布

[原始来源](https://github.com/chenkangjie1123/VGGT-Diff)

## Franka Stack

**具身智能 · REAL ROBOT STACK**

一套面向 Franka Panda 的端到端实机工程栈，串起 GELLO/VR 示教、LeRobot v2.1 数据转换、OpenPI π0.5 训练与部署，并给出 1 kHz 底层控制、双 RGB 采集和 20 Hz 轨迹记录配置。

## 今日深挖：今日深挖 · swin2sr-rs

swin2sr-rs 的长期价值不在提出新的超分网络，而在把已有 Swin2SR 权重做成低摩擦的本地执行层：模型用 safetensors，CPU 与 CUDA 共用一个二进制，自动分块可控制峰值内存，部署时不再携带整套 Python/深度学习框架。代价也很清楚：分块边缘缺少全图上下文，结果可能与整图模式存在可测差异；当前输入输出聚焦 PNG，预编译平台主要是 Linux，模型质量上限仍受既有 Swin2SR 检查点限制。建议先用 realworld-x4 在自己的退化图像上记录延迟、峰值 RAM/VRAM、接缝和 NIQE/LPIPS，再决定是否接入生产；视频场景则应与 fast-rtxvsr 的全 GPU 管线分开评估。

[查看原始项目](https://github.com/jacobsparts/swin2sr-rs)
