## InvokeAI 7.0 alpha 1：生成、画布、视频与超分合并为工作台

**图像 / 视频生成 · OCT 04 ALPHA**

新项目模型会保存画布、生成设置、工作流、队列和独立图库；可导出 .invk。新 Canvas 支持图层组、16 种混合模式、非破坏调整、压感笔刷、选择、文字、自定义字体、历史回看与 PSD 导出，Video 面板覆盖 MiniMax H3 与 LTX-2.5 音视频路径。

这是对本地视觉工作流的重大重构，但明确属于 alpha。v7 需要 Python 3.12，数据库迁移不可回退给 v6；测试必须使用全新 root，不能指向现有生产图库。显存仍由所选图像/视频模型决定，界面统一不等于低配硬件能运行所有模型。

Apache-2.0 · Python 3.12 · 本地 GPU · alpha · 数据库迁移单向

[原始来源](https://github.com/invoke-ai/InvokeAI/releases/tag/v7.0.0-alpha.1)

## uv 0.12.23：只靠 uv.lock 做 frozen 恢复

**Python 工具链 · OCT 04 RELEASE（中国时区）**

预览功能允许在没有 workspace manifest 时，用 frozen-lockfile 对 uv.lock 执行 sync、export、tree 与 workspace metadata；同时加入 CPython 3.15 rc3。

适合构建产物或缓存层只携带锁文件的复现流程。该能力仍是 preview，且锁文件无法替代业务配置与私有索引凭据；Windows ARM64 上还修复了 x86-64 Python 仿真环境误编译 win_amd64 wheel 的问题。

Apache-2.0 / MIT · Windows / Linux / macOS · frozen lockfile · preview

[原始来源](https://github.com/astral-sh/uv/releases/tag/0.12.23)

## pnpm v12.9.1：WebContainer WASM 拆包，主包回到约 4 MB

**Node.js 工具链 · OCT 04 RELEASE（中国时区）**

StackBlitz WebContainer 的 WASM 构建独立为 @pnpm/wasm，pnpm 主包从约 55 MB 回到约 4 MB；同时修复 GitLab CI provenance 发布、私有 registry 重定向 TLS 和 frozen lockfile 兼容。

浏览器容器需显式安装 @pnpm/wasm，原生环境仍使用本地可执行文件。对 monorepo 和 CI，包体缩小是真实收益，但这是安装分发变化；升级前要核对 WebContainer 镜像与自更新策略，避免同时存在 Homebrew 与自更新副本。

MIT · Node.js / WebContainer · WASM 拆包 · provenance

[原始来源](https://github.com/pnpm/pnpm/releases/tag/v12.9.1)

## Tokio 1.53.2：集中修补关停、锁与 mpsc 边界

**异步运行时 · OCT 04 RELEASE**

修复 buffered relative seek 整数溢出、Windows child handle 关闭前未注销 wait、blocking pool 关停锁顺序、mpsc 索引回绕与 Permit 发送，以及 timer/waker 在锁内释放的问题。

这些不是普通依赖刷新：它们落在高并发服务最难复现的停机、取消和 wraparound 路径。使用 Tokio 进程、文件 I/O、定时器或 channel 的服务应升级后跑关停与压力测试；io_uring 与 taskdump 的若干修复仍属于 unstable。

MIT · Rust · 跨平台 · shutdown · mpsc · timer

[原始来源](https://github.com/tokio-rs/tokio/releases/tag/tokio-1.53.2)

## 今日深挖：今日深挖：InvokeAI 7 把生成工具改造成可恢复项目系统

它不再把生成、画布、工作流、视频和超分视为互不相干的页面，而是把它们放进一个可自动保存、可导出的项目状态中；这比单纯新增模型更接近长期创作工具。风险同样清楚：数据库迁移不可逆、界面和画布引擎重写、alpha 明示会破坏数据。最合理的下一步是在新 root 中导入一套非关键工作流，测试崩溃恢复、双窗口同步、PSD/.invk 导出和显存峰值，绝不原地升级 v6。
