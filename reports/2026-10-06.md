## llama.cpp v0.6.0：统一 token、embedding 与状态批处理

**本地 LLM 推理 · OCT 06 RELEASE（中国时区）**

扩展 batch API 新增 llama_process，可在同一批次处理 token、embedding 与 MTP/deepstack 状态；同时支持 GLM-5.3-Flash、Clef 视觉决策模型、Qwen4Exp MTP，并升级 ggml 0.26。

Metal、Vulkan、CUDA、WebGPU、OpenCL、SYCL、Hexagon 与 Windows ARM64 都有新增路径；官方报告 Apple GPU 小批量矩阵内核最高约 3×，但该数字不是所有模型的端到端速度。session/state 版本与 C API 同时变化，嵌入式应用应先验证旧会话恢复、批尺寸、峰值内存和数值一致性。

MIT · CPU / Metal / CUDA / Vulkan / WebGPU · API 与 session 格式变更

[原始来源](https://github.com/ggml-org/llama.cpp/releases/tag/v0.6.0)

## ComfyUI v0.39.0：离线开关与模型资产库加固

**图像 / 视频生成 · OCT 06 RELEASE（中国时区）**

加入 --offline 与 --disable-partner-nodes，自动在集成显卡上关闭 pinned memory；修复 Qwen-Image 2.1 int8/int4 缓存崩溃、MiniMax H3 VAE 卸载，并改善 16-bit EXR、视频保存和资产扫描事务。

对本地优先用户，明确关闭联网节点比新增云模型更重要。Windows、Linux、macOS 都能使用，显存取决于模型与量化；升级前仍需备份环境并检查自定义节点，因为前端和资产数据库改动较多。

GPL-3.0 · Windows / Linux / macOS · 离线模式 · int8/int4 修复

[原始来源](https://github.com/Comfy-Org/ComfyUI/releases/tag/v0.39.0)

## Diffusers v0.41.0：Qwen-Image 2.1 与分片加载

**扩散模型工具链 · OCT 06 RELEASE**

集成 Qwen-Image 2.1 的文生图、编辑、多参考图、原生 RGBA、LoRA 训练与单文件加载；另加入 LTX-2.5 DFR、Cosmos 3 SeaCache 和 W8A8/W8A16 去噪。

张量并行加载让每个 rank 只读取自己的权重分片，降低加载阶段内存，但它仍是 Python/PyTorch 工具链而非一键桌面应用。ONNX 支持已弃用，依赖 ONNX Runtime 的现有流程应迁移到 Optimum 并做兼容回归。

Apache-2.0 · Python / PyTorch · Qwen-Image 2.1 · TP 分片加载

[原始来源](https://github.com/huggingface/diffusers/releases/tag/v0.41.0)

## OpenHands v1.25.0：多后端控制台补齐会话边界

**编码 Agent · OCT 06 RELEASE**

Agent Canvas 增加批量模型配置、启动时模型路由、服务端工具目录和原生 Git 自动化入口，并修复移动端 WebSocket、云端限流、委派任务追踪和监听地址上的会话密钥暴露。

它能本地、Docker、VM 或远端运行 OpenHands、Claude Code、Codex、Gemini 与 ACP Agent。无沙箱模式会让 Agent 直接访问主机文件；多 Docker 对话隔离执行，但共享同一宿主工作区仍会冲突，应该配独立目录或 worktree。

MIT · Node.js 24+ · Docker 可选 · loopback 会话密钥 · 工作区隔离

[原始来源](https://github.com/OpenHands/OpenHands/releases/tag/v1.25.0)

## Lazygit v0.66.0：分支栈操作进入主视图

**CLI / 终端 · OCT 06 RELEASE（中国时区）**

可直接在主视图 stage、unstage、discard，按栈顺序展示分支，并一次推送重写后的分支栈；还可判断分叉来自本地重写还是上游重写，并在不 checkout 的情况下快进分支。

适合频繁 rebase、worktree 与 stacked branches 的终端用户。新版同时加入动态深浅主题和更准确的提交图字符，但批量推送/丢弃仍是高影响操作；应先在非关键仓库熟悉确认提示和自定义键位。

MIT · Windows / Linux / macOS · 分支栈 · worktree · TUI

[原始来源](https://github.com/jesseduffield/lazygit/releases/tag/v0.66.0)

## 今日深挖：今日深挖：llama.cpp 的 v0.6 不只是新增模型

扩展 batch API 把 token、embedding 与每 token 状态放进同一执行语义，为 MTP、多模态和 decision-model 服务端接口提供共同基础；ggml 0.26 再把稀疏注意力、W4A4、BF16 与移动 DSP 后端向下铺开。长期价值在统一，而风险也来自统一：API、session 格式和多个后端同时改变。下一步最值得做的是在固定量化文件上对照 v0.5/v0.6 的首 token、持续吞吐、会话恢复和峰值内存，而不是只跑一次启动测试。
